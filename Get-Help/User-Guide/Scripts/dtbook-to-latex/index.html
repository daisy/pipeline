DTBook to LaTeX

Transforms a DTBook (DAISY 3 XML) document into a LaTeX document suitable for large print production.

Synopsis

Inputs

  • DTBook
    The DTBook 2005 XML file.
    Media-type:
    • application/x-dtbook+xml
    Sequence: no

Outputs

  • LaTeX
    The output LaTeX document.
    Media-type:
    • application/x-latex

Options

  • Page style
    Page style for the generated LaTeX.
    Possible values: One of the following:
    plain
    compact
    spacious
    withPageNums
    scientific
    Default value: plain
  • Alignment
    Alignment for standard text.
    Possible values: One of the following:
    justified
    left
    Default value: justified
  • Bottom margin
    Bottom margin of the page (e.g. "20mm").
    Possible values: Any <string>
    Default value: 20mm
  • Font
    Font for the generated LaTeX. This can be any installed TrueType or OpenType font (e.g. "Tiresias LPfont", "Latin Modern Roman").
    Possible values: Any <string>
    Default value: LMRoman10 Regular
  • Backup font
    Optional secondary font for specific Unicode ranges (see backup-unicode-ranges).
    Optional secondary font for specific Unicode ranges (see backup-unicode-ranges).

    Requires the ucharclasses package.

    Possible values: Any <string>
    Default value: Arial Unicode MS
  • Line spacing
    Line spacing in the generated LaTeX.
    Possible values: One of the following:
    singlespacing
    onehalfspacing
    doublespacing
    Default value: singlespacing
  • Default language
    Language for the babel package when no xml:lang attribute is present.
    Language for the babel package when no xml:lang attribute is present.

    See the babel user guide for all valid values.

    Possible values: One of the following:
    english
    English
    ngerman
    German (new/reformed orthography, post-1996)
    USenglish
    English (American)
    UKenglish
    English (British)
    swedish
    Swedish
    canadian
    English (Canadian)
    french
    French
    Default value: english
  • Top margin
    Top margin of the page (e.g. "20mm").
    Possible values: Any <string>
    Default value: 20mm
  • Replace emphasis with quotes
    Replace em elements with quoted text.
    Replace em elements with quoted text.

    Emphasis can be hard to render in large print.

    Possible values: true or false
    Default value: false
  • Font size
    Font size for the generated LaTeX.
    Font size for the generated LaTeX.

    See also the documentation of the extsizes package.

    Possible values: One of the following:
    12pt
    14pt
    17pt
    20pt
    25pt
    Default value: 17pt
  • Left margin
    Inner (left) margin of the page (e.g. "28mm").
    Possible values: Any <string>
    Default value: 28mm
  • Stock size
    Stock size for the generated LaTeX.
    Possible values: One of the following:
    a3paper
    ISO 216 A3 paper size
    a4paper
    ISO 216 A4 paper size
    a5paper
    ISO 216 A5 paper size
    letterpaper
    Letter paper size (11 in × 8.5 in)
    legalpaper
    Legal paper size (14 in × 8.5 in)
    executivepaper
    Legal paper size (10.5 in × 7.25 in)
    Default value: a4paper
  • Right margin
    Outer (right) margin of the page (e.g. "20mm").
    Possible values: Any <string>
    Default value: 20mm
  • Paper height
    Height of the paper (e.g. "250mm").
    Possible values: Any <string>
    Default value: 250mm
  • Endnotes
    Put notes at the end of the chapter or document instead of as footnotes on the same page.
    Possible values: One of the following:
    none
    document
    chapter
    Default value: none
  • Backup Unicode ranges
    Comma-separated list of Unicode ranges (camel case) for which the backup font is used, e.g. "Arabic,Hebrew,Cyrillic,GreekAndCoptic".
    Possible values: Any <string>
    Default value:
  • Paper width
    Width of the paper (e.g. "200mm").
    Possible values: Any <string>
    Default value: 200mm
  • Include Images
    Whether to include or ignore images in the LaTeX output.
    Possible values: true or false
    Default value: true 
Usage: dp2 [GLOBAL_OPTIONS] dtbook-to-latex [OPTIONS]

Options:
--source source The DTBook 2005 XML file.
--page-style [page-style] Page style (default: plain)
--alignment [alignment] Alignment (default: justified)
--bottom-margin [bottom-margin] Bottom margin (default: 20mm)
--font [font] Font (default: LMRoman10 Regular)
--backup-font [backup-font] Backup font (default: Arial Unicode MS)
--line-spacing [line-spacing] Line spacing (default: singlespacing)
--default-language [default-language] Default language (default: english)
--top-margin [top-margin] Top margin (default: 20mm)
--replace-em-with-quote [replace-em-with-quote] Replace emphasis with quotes (default: false)
--font-size [font-size] Font size (default: 17pt)
--left-margin [left-margin] Left margin (default: 28mm)
--stock-size [stock-size] Stock size (default: a4paper)
--right-margin [right-margin] Right margin (default: 20mm)
--paper-height [paper-height] Paper height (default: 250mm)
--endnotes [endnotes] Endnotes (default: none)
--backup-unicode-ranges [backup-unicode-ranges] Backup Unicode ranges (default: )
--paper-width [paper-width] Paper width (default: 200mm)
--include-images [include-images] Include Images (default: true)
-o,--output [OUTPUT] Path where to store the results. This option is mandatory when the job is not executed in the background
-z,--zip Write the output to a zip file rather than to a folder
-n,--nicename [NICENAME] Set job's nice name
-r,--priority [PRIORITY] Set job's priority (high|medium|low)
-q,--quiet Do not print the job's messages
-p,--persistent Delete the job after it is executed
-b,--background Sends the job and exits

Requirements

The script produces a .tex file that must be compiled with XeLaTeX or LuaLaTeX (required for font selection via fontspec). The following LaTeX packages must be installed:

  • memoir class
  • fontspec, babel, hyperref, setspace
  • tcolorbox (a recent version is required for sidebars to render correctly)
  • adjustbox, enumitem, url, alphalph
  • ucharclasses (optional, only needed for the backup-unicode-ranges option)

Note: Producing accessible tagged PDF (PDF/UA-2) requires TeX Live 2025 or later, LuaLaTeX, and changes to the generated LaTeX preamble. This is not currently supported by this script but may be addressed in a future version. See the LaTeX Tagging Project for background.
